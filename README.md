# Timeplanner
Timeplanner — зручний вебзастосунок для планування дня, тижня та особистих справ. Допомагає розставляти пріоритети, розподіляти час між завданнями, відстежувати виконання й підтримувати фокус. Проєкт створено як легкий інструмент для впорядкованої, спокійної та продуктивної роботи. Керуй часом ясно.
